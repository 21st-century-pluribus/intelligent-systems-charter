# About this charter

The Intelligent Systems Charter is an independent, vendor-neutral text. It is not a product and it is not owned by one. It is maintained under the name 21st Century Pluribus.

## What is here

- [The charter](/charter/): the Declaration, the Universal Principles and the Constitution. These are the founding texts and they change rarely.
- [The proposal](/proposal/): one way to enforce the charter in running software. The charter binds; the proposal suggests. Where they disagree, the charter governs.
- [Essays](/essays/): the case for the charter.
- [Changelog](/changelog/): every change, with the reason for it.

## Adopting it

An adopter is any person or organization that commits to the charter and governs its intelligent systems under it. Adopters may add stricter rules of their own. They may not loosen the universal principles. There is nothing to sign and no fee. If you adopt it, saying so publicly helps others do the same.

## Changing it

Article IX of the Constitution governs amendment: a change to the universal principles needs a published, versioned amendment with a stated rationale. In practice that means a pull request in the [public repository](https://github.com/21st-century-pluribus/intelligent-systems-charter) that explains why, and an entry in the changelog. The Declaration is not amended.

## Using the text

The charter is licensed under [Creative Commons Attribution 4.0](/license/charter-cc-by-4.0.txt). You may copy, share, translate and adapt it, including commercially, if you give credit and say what you changed. The proposal is licensed under the [Apache License 2.0](/license/proposal-apache-2.0.txt), so anyone may implement it in any product.

If you change the normative text, please publish your version under a different name, so that "Intelligent Systems Charter" always refers to one text.

## This site

The site is built directly from the Markdown files in the repository, which are the canonical source. It sets no cookies and loads no fonts from third parties. Pages with diagrams load one open-source drawing library; without JavaScript the diagrams appear as readable text.

To learn whether the charter is being read, the site counts page views with [Umami](https://umami.is), an open-source analytics service. For each view it records the page, the referring site, the browser, device type and an approximate location (country, region and city) derived from the network address. It stores no network addresses and sets no cookies. To count unique visitors it keeps a one-way hash of the network address and browser, mixed with a secret value that changes every month, so a returning visitor cannot be recognized from one month to the next. Query strings are not collected, and if your browser sends a Do Not Track signal, nothing is recorded. Blocking the script has no effect on the site.
